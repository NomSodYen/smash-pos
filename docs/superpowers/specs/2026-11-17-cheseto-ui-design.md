# v25 UI แนว Cheseto (แรงบันดาลใจเท่านั้น)

- เป้าหมาย: หน้าตาสะอาด อ่านง่ายแบบภาพ Cheseto Restaurant POS (Dribbble) ที่เจ้าของร้านชอบ โดยไม่เปลี่ยนขั้นตอนขาย
- ห้าม: แตะ/ล้างข้อมูลบิลใน localStorage, ใช้ของเสียเงิน, ก๊อปภาพหรือแบรนด์ของเขา
- ธีม: สว่างเป็นค่าเริ่มต้น สลับเป็นมืดกระทะร้อน (v20) ได้ในตั้งค่า เก็บที่ `smash.theme`
- ที่เปลี่ยน: ปุ่มแท็บมีไอคอน, การ์ดยอด/บิลวันนี้บนหน้าขาย, การ์ดเมนูรูปวงกลม+ราคาสีส้ม+ขายวันนี้ X ชิ้น,
  ออเดอร์มีปุ่มทานที่ร้าน/กลับบ้านแบบเม็ดยา ไอคอนกลม ปุ่ม −/+ กลม, สรุปยอดมีการ์ด 4 ช่อง + กราฟรายชั่วโมง + ป้ายสีวิธีจ่าย
